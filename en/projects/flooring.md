# Flooring services

**PHP · live**

Brochure site for a company laying, sanding and finishing wooden floors:
service descriptions, reference images and a quote form.

## Approach

In this trade customers decide from **before-and-after images**, so the site is
built around work photos rather than text, and the quote form is reachable from
every page.

A few pages that don't need a framework — deliberately written in plain PHP.
Choosing the tool that fits the size of the job, instead of putting the same
framework on everything, also keeps maintenance cheap.
